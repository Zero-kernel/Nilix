# Fuzz Test Reports

This directory contains structured fuzz test reports generated by CI.

## Report Format

Each report is named `RYYYYMMDD-HHMMSS.md` and contains:

- **Summary table**: Coverage, new units, exec/sec, warnings per target
- **Quality issues**: Targets with no coverage growth or stub implementations
- **Crashes**: Any discovered crashes/timeouts/OOMs
- **Detailed statistics**: Full libFuzzer stats per target
- **Recommendations**: Actionable improvements based on results
